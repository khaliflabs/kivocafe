# KIVO Café

KIVO Café is a mobile-first café ordering platform.

## Initial application

- `apps/mobile` — React Native / Expo / TypeScript mobile application

Expo and React Native have not been initialized yet. The current repository contains only the base workspace structure.

## Planned capabilities

- Mobile ordering
- Menu browsing
- Product customization
- Cart
- Pickup orders
- Payments
- Loyalty and rewards
- Notifications
- Order management
- Staff and admin portal
