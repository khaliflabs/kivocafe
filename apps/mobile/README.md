# KIVO Café mobile

React Native, Expo, TypeScript, and Expo Router foundation for the KIVO Café customer application.

## Run locally

```bash
cd /home/kivo/projects/kivocafe/apps/mobile
npm install
npx expo start
```

Use the QR code printed by Expo CLI with the appropriate Expo Go workflow on a compatible device. Native store builds and deployment are not configured yet.

## Quality checks

```bash
npm run lint
npm run typecheck
npx expo-doctor
```
